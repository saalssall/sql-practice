# SQL Practice

This repository is a hands-on space for learning and improving SQL skills. It focuses on practicing core database concepts through real queries, exercises, and examples.

## What you'll practice
- SELECT statements
- Filtering with WHERE
- Sorting with ORDER BY
- Aggregate functions like COUNT, SUM, AVG, MIN, and MAX
- GROUP BY and HAVING
- JOIN operations
- Subqueries and nested logic
- Data cleaning and basic analysis

## Purpose
The goal of this repo is to help build confidence in writing and understanding SQL queries for real-world data tasks.

## Getting started
1. Open the SQL files in this repository.
2. Run the queries in your preferred SQL environment such as PostgreSQL, MySQL, or SQLite.
3. Practice modifying queries to explore different results and edge cases.

## Notes
This project is intended for learning, experimentation, and consistent SQL practice.
